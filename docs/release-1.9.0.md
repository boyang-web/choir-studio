# 和声练习室 1.9.0

- 新增《回声》：两组合唱队、八个独立声部、三页原谱、38 小节，用户确认练习速度 120 BPM。
- 保留原 PDF，提供 MusicXML 与标准 MIDI；逐符头音高、304 个声部小节和 462 对回声事件完成自动检查。
- 八声部独听、循环、变速、跟谱和离线音色可用。
- 删除局域网资源更新、手机离线转发和 APK 下载服务。内容更新统一通过重新下载安装包完成。
- 新增 macOS 离线 DMG，继续提供 Windows 便携 EXE 与 Android APK。

下载对应系统的安装包即可使用；无需部署 Node.js 或 Python。`SHA256SUMS.txt` 用于校验下载文件。

macOS 包暂未使用 Apple Developer ID 签名或公证，首次运行可能需要在系统“隐私与安全性”中确认打开。
Windows 包需要 WebView2 Runtime。本版 Android APK 为新调试签名构建，若与旧安装包签名不同，需要先卸载旧版再安装；卸载会清除本机练习设置。

《回声》的 120 BPM 为练习设定，原谱仅写 Allegro。校验结果不等同于音乐人员逐声部听感签收；
原有试导入曲目仍保留“待校订”标识。详见仓库 `docs/回声核验记录.md`。
