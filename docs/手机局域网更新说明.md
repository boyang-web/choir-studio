# 手机局域网更新

首次使用需要安装项目根目录 `releases/` 中的「和声练习室.apk」（当前为 1.8.0）。覆盖安装即可，练习设置保留。已经安装 1.7.0 的用户可直接通过局域网更新接收新曲库。

## 手机传给手机

分享方和接收方首次安装 1.7.0 后，即可离线传递；尚未安装的人也可以先在分享手机的网页下载安装包。

1. 分享方手机先获得需要传递的内容，可以从电脑更新，也可以从另一部手机接收。
2. 分享方在系统设置开启个人热点，回到应用的「控制台 → 离线传递给别人」，点「分享当前版本」。
3. 接收方连接这个热点，在应用的「控制台 → 局域网更新」填写分享方显示的地址，例如 `http://192.168.43.1:5174`，再点「检查更新 → 下载并使用」。以分享方实际显示的地址为准。
4. 尚未安装应用的接收方先用浏览器打开该地址，下载并安装 APK，然后按第 3 步接收分享方的当前内容。APK 自带内容可能比分享方后来保存的内容旧，因此安装后还应检查一次更新。
5. 接收完成后可以断开热点离线练习；接收方也能开启自己的热点，将收到的内容继续传给别人。

分享方不需要连接电脑或互联网。接收方需要主动确认下载，应用不会强制安装或替换。分享期间支持短暂切到后台，30 分钟自动停止，也可以在应用或系统通知中手动停止；分享期间不能替换本机的内容，需先停止分享。

如果显示多个地址，选择热点网卡的地址；部分手机的热点或省电限制可能影响连接，双机使用仍需实测。不能连接时先保持分享应用在前台，再确认热点已开启及地址正确。

## 从电脑更新手机

1. 电脑双击项目根目录的「启动合唱练习室.bat」，保持启动窗口打开。
2. 手机和电脑连接同一个 Wi-Fi。
3. 手机打开应用，进入「控制台 → 局域网更新」。
4. 填写电脑启动窗口显示的地址，例如 `http://192.168.1.10:5173`。若窗口显示多个地址，选择电脑当前 Wi-Fi 的 IPv4 地址，通常不选虚拟网卡地址。
5. 点击「检查更新」。有更新时再点「下载并使用」，应用保存完成后会重新打开。

以后电脑上的乐谱、音频数据或页面改好了，手机重复第 5 步即可。没有更新时会提示已是最新内容。下载时会校验全部文件，相同内容直接复用；保存完成后可以关闭电脑、断开 Wi-Fi，继续在手机上练习。

连接失败时，确认电脑启动的是 BAT 服务、地址和端口正确、Windows 防火墙允许 Node.js 在专用网络中接收连接。仅打开独立 EXE 不会启动手机更新服务。电脑不需要连接互联网。

下载中断或校验失败不会替换原内容。新内容启动后 30 秒内无法完成初始乐谱加载，会退回先前版本；尚未确认成功就退出应用，下次启动也会退回。控制台的「恢复安装版内容」可以恢复此 APK 自带的内容，保留练习设置。

电脑的 `choir-studio/.update-keys/private.pem` 是这批手机识别更新来源的密钥，请在本地保留并备份。它不在网页、APK 或分发 ZIP 中；更换更新电脑时需要将 `.update-keys` 文件夹一并迁移，否则已安装的手机会拒绝其更新。

本功能更新网页、曲库、乐谱、MIDI 和采样等资源。修改安卓权限或原生功能时，仍需要安装新版 APK。手机需要在能够连到这台电脑的局域网中才能获得新内容。

验证：31 项 Node 测试、33 项 Java 校验/暂存检查通过；181 个文件完成真实本地 HTTP 下载、跨语言签名验证和无网络复用测试。手机分享共用的 HTTP 代码通过 A → B → C 两跳传递、签名保留、安装包端点及非法请求等 193 项检查。尚未在手机实机上验证热点、后台服务、安装、WebView 切换和启动失败回退。
