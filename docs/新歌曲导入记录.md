# 新歌曲试导入（2026-10-31）

声部名称已统一为“女中音”，保留 `alto` 数据标识，使原有音量和声部设置继续有效。生成脚本也已同步修改。

新歌使用本地 Audiveris 识谱，再从 MusicXML 生成标准 MIDI、声部数据和谱面定位。原始 PDF 保存在 `data/sources/`，应用提供的 PDF 与来源文件内容一致。带封面的文件仅在识谱时跳过封面，应用中仍保留全部页面。

四首试导入歌曲会显示在曲库中，均标为“试导入 · 待校订”。识别结果含漏音、节奏及连线问题，不能视为已完成逐音校对的练习音轨。各曲的机器核对清单位于 `inspection/new-imports/*-audit.json`。

核对项是机器标记的检查位置，包含同一小节多个声部的问题，不等同于已确认的错音数量。

《为要寻一个明星》的扫描页出现单个谱表被识别为独立系统，以及钢琴谱表与人声分组不稳定的问题。目前无法可靠保证声部对应关系，需要先在 Audiveris 校正谱表与系统，再导出。导入脚本遇到这种情况会停止，并写入失败原因。

新歌按谱面顺序播放，尚未展开反复跳转。MusicXML 中没有识别出音符或休止的空小节、超出拍数的音符及未处理的倚音均列入核对清单；没有用压缩时值隐藏识别异常。原有两首歌的逐小节纠错规则不会套用到新歌。

## 复现与重试

在项目根目录执行，`--id` 对应 `tools/new-scores.json` 中的歌曲标识：

```powershell
python tools/transcribe_new_scores.py --id ye-lai-xiang
python tools/import_new_scores.py --id ye-lai-xiang
```

仅调整数据导入逻辑、复用已经校正导出的 MusicXML 时：

```powershell
python tools/import_new_scores.py --id ye-lai-xiang --reuse-export
```

识谱工作目录及日志位于 `data/omr/new/<id>/`。修改曲库后，运行原有 Windows、Android 构建脚本即可将当前曲库打入安装包；已有安卓 1.7.0 用户也可通过局域网更新接收网页与曲库。
