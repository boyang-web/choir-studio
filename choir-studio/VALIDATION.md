# 1.7.0 手机离线传递验证

日期：2026-10-30。

- 新增「离线传递给别人」：分享手机启用热点后，通过原生本地 HTTP 服务提供当前有效清单、按散列寻址的文件以及已安装的 APK；接收手机使用现有「局域网更新」流程校验、暂存并切换。无需电脑及互联网。
- APK 内置完整签名清单；从电脑或手机收到更新时一并保存原签名清单。转发只复用原签名，不在手机分发签名私钥。接收方获得全部当前内容后，可以继续转发。
- 分享采用用户主动启动的 dataSync 前台服务，支持停止操作并在 30 分钟后自动结束，持有同期限的部分唤醒锁。仅接受来自私有 IPv4 的客户端，限制连接数、队列和请求头大小，只允许 GET/HEAD 读取指定端点。分享期间禁止安装更新或恢复本机资源，避免传输过程中移除文件。
- Node 自动测试 31 项通过；Java 校验与暂存检查 33 项通过。用 APK 共用的 `RelayHttpServer` 和 `UpdateFiles` 实现，完成 181 个文件 A → B → C 两跳 HTTP 转发、签名保留、安装包端点、非法路径、方法和 HEAD 等 193 项检查。
- Android 1.7.0 / versionCode 11；Windows 1.7.0.0。手机的 APK 下载端点提供本机已安装的原始 APK；后来保存的资源由更新端点继续同步。
- 限制：测试在电脑上运行传输与校验代码，不能替代双手机热点及 Android 前台服务实测。手机厂商的热点网络和省电策略仍可能影响连接。真实 WebView 切换、Activity 生命周期、回退及锁屏传输仍未实机验证。

# 1.6.0 局域网更新验证

日期：2026-10-30。

- 手机控制台增加更新源地址、检查更新、下载并使用、恢复安装版内容；地址在连接并验签成功后保存。网页及 Windows 不显示安卓专属入口。
- 电脑 Node 服务从当前 public 资源生成签名清单，以内容散列识别修订。修正乐谱后无需提高安装包版本号。文件通过 SHA-256 地址从内存快照发送；传输内容必须匹配签名清单，否则手机拒绝切换。电脑 RSA 私钥保存在 `.update-keys/private.pem`，公钥内置于 APK 的非网页资源中。
- 原生更新入口只接受私有 IPv4 的 HTTP 根地址，禁止域名、凭据、远程公网地址和 HTTP 重定向。每个文件校验大小与 SHA-256；限制路径、重复条目、清单大小及总大小。
- 所有文件先暂存到独立目录，复用的本地资源同样经过校验。全部成功后持久保存版本指针并切换本地 WebView。网络中断、错误内容或空间不足时保留旧版。新页面在初次乐谱载入成功后确认就绪；30 秒未确认或确认前进程退出时回退。恢复安装版保留浏览器练习设置。
- 30 项 Node 自动测试通过，包括签名、错误签名、内容更新检测、控制台状态、更新失败与重试；33 项直接运行 APK 共用 Java 代码的地址、签名、文件暂存、文件损坏和中断清理检查通过。
- 实际启动电脑服务，完成 Node 签名清单到 Java 验签、181 个文件 HTTP 下载、再次禁用网络源后的完整复用测试。
- Android 1.6.0 / versionCode 10。安装包资源与当前 public 逐文件比较；内置内容修订和电脑服务修订一致。
- 限制：本机没有完成手机实机验收。纯 Java 测试不覆盖 Android SharedPreferences、Activity 生命周期和真实 WebView 切换；自动回退逻辑已编译但仍需实机验证。此功能需要首次安装一次新 APK，原生能力变更仍需要安装 APK。
